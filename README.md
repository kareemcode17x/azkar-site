# الأذكار

موقع مجاني ومفتوح المصدر: أذكار الصباح، أذكار المساء، سورة الكهف، وحديث جديد كل يوم.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية وحديث اليوم |
| `morning.html`, `evening.html` | صفحتا الأذكار (نفس القالب) |
| `mawaqit.html`, `mawaqit.js` | مواقيت الصلاة (مدن مصر) مع العدّ التنازلي |
| `quran.html`, `quran.js` | القرآن الكريم كامل: فهرس وبحث وقراءة وتلاوة (`kahf.html` يحوّل لسورة الكهف) |
| `data/morning.js`, `data/evening.js` | نصوص الأذكار وعدد التكرار والفضل |
| `style.css` | التصميم المشترك والوضع الليلي |
| `app.js`, `azkar.js` | تبديل الثيم، والعدّاد وحفظ التقدّم |

## إضافة أو تعديل ذكر

عدّل الملف داخل `data/` بإضافة عنصر بالشكل `{ text: "...", fadl: "...", count: 3 }` (حقل `fadl` اختياري).

## التشغيل

لا يحتاج بناء. افتح `index.html` أو انشره على GitHub Pages.

## فحص القرآن (نص وصوت)

```
python3 tools/check_text.py   # يفحص النص: عدد الآيات والترقيم والرموز والبسملة لكل السور
bash tools/check_audio.sh      # يفحص إن ملفات التلاوة الـ 114 موجودة وحجمها منطقي
```
